1. PASSWORD SECURITY [20 Marks] — Targeting: 15–20 (Exceeds Standard)
───────────────────────────────────────────────────────────────────────────────

BASIC REQUIREMENTS MET:
• bcrypt password hashing with 12 salt rounds (industry standard)
• Passwords never stored in plain text
• Strong password policy enforced via RegEx:
  - Minimum 8 characters, maximum 30
  - Must contain: uppercase, lowercase, number, special character
  - Pattern: /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&#])[A-Za-z\d@$!%*?&#]{8,30}$/

EXCEEDS STANDARD (Additional Research):
• express-brute middleware — per-IP brute force protection
  - 5 free retries before lockout
  - Lockout escalates: 5 minutes → 1 hour
  - Separate from general rate limiting
• express-rate-limit — 10 login attempts per 15 minutes (server-wide)
• JWT tokens expire after 1 hour (prevents session hijacking)
• No password hints or recovery (accounts managed by admin only)

FILES: backend/routes/auth.js, backend/models/User.js

4. OVERALL FUNCTIONING OF THE WEB APP [20 Marks] — Targeting: 15–20
───────────────────────────────────────────────────────────────────────────────

BASIC REQUIREMENT MET:
• Web application is correctly configured and secured
• Customer portal: login → create international payment
• Employee portal: view transactions → verify → submit to SWIFT
• Information flows correctly from customer to staff portal

SECURITY PROTECTIONS AGAINST ALL LISTED ATTACKS:
• XSS — Helmet.js (X-XSS-Protection, CSP headers)
• Clickjacking — X-Frame-Options: DENY via Helmet
• Man-in-the-Middle — HTTPS/SSL encryption (RSA 2048)
• DDoS — Rate limiting (100 req/15min general)
• Brute Force — express-brute + auth rate limit (10/15min)
• SQL/NoSQL Injection — Mongoose schema validation + RegEx whitelisting
• MIME Sniffing — X-Content-Type-Options: nosniff via Helmet
• Session Hijacking — JWT with 1-hour expiry
• CORS attacks — Origin restricted to frontend URL only
• Large Payload — Request body limited to 10kb

EXCEEDS STANDARD:
• Defence in depth: input validated on BOTH client and server
• Content Security Policy (CSP) enforced via Helmet AND HTML meta tag
• All traffic encrypted — no HTTP fallback
• Automated deployment script for easy setup
• Comprehensive API test suite proves functionality

FILES: backend/server.js, frontend/public/index.html, all route files
